# WMS 系统功能说明

## 核心功能

### 仓库与库位管理
*   **库位分配规则**：
    *   **专属库位模式**：当商品首次在某个仓库上架时，系统会自动为该商品批量生成 10 个专属库位（`InventoryItem` 记录）。
    *   **编号格式**：`A-{Shelf}-{Slot}`（如 `A-01-01` 至 `A-01-10`）。其中 `Shelf` 为货架号，系统自动递增（每个新商品分配一个新的货架号），`Slot` 固定为 01-10。
    *   **容量限制**：每个库位默认容量上限为 100 件。该商品在单仓库的总容量上限为 1000 件。
    *   **分配逻辑**：后续上架时，系统会自动检查剩余空间，按库位编号顺序（A-XX-01 -> A-XX-10）填充库存。若总库存超过 1000 件，系统将阻断入库并提示错误。

### 入库管理
*   支持入库单创建、审核、收货、上架全流程。
*   上架时自动推荐库位，支持预览分配结果。

### 数据统计
*   **时区支持**：系统强制使用北京时间（Asia/Shanghai）进行数据统计和展示，确保日报表和工作台数据的准确性。
*   **统计口径**：工作台和数据大屏的“今日入库/出库”指标统计的是**商品总数量**（而非单据数）。

### 数据库维护

项目提供数据库结构与数据的 SQL 导出文件，方便进行数据迁移或备份。

*   **SQL 导出文件**：`backend/wms_db_dump.sql`
*   **包含内容**：完整的数据库表结构（DDL）以及当前的业务数据（DML）。
*   **更新方式**：如需重新生成该文件，可以使用以下 Python 代码片段或执行相关导出脚本：
    ```python
    import sqlite3
    conn = sqlite3.connect('backend/db.sqlite3')
    with open('backend/wms_db_dump.sql', 'w', encoding='utf-8') as f:
        for line in conn.iterdump():
            f.write('%s\n' % line)
    conn.close()
    ```

## 开发与维护

### 数据初始化
系统提供了一键重置和初始化演示数据的脚本，用于快速搭建测试环境。
运行方式：
```bash
cd backend
python rebuild_data.py
```
该脚本会：
1.  清空现有所有业务数据。
2.  创建默认管理员 (`admin` / `123456`) 和角色。
3.  创建基础数据（仓库、供应商、客户、商品）。
4.  模拟商品首次入库，自动生成专属库位结构。
5.  创建示例入库单据。

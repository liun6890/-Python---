# 智仓通 WMS：基于前后端分离架构的现代化仓库管理系统

## 摘要 (Abstract)
本文档旨在论证“智仓通 WMS”的设计与实现。系统采用 Vue3 组合式 API 与 Django REST Framework (DRF) 构建，解决了传统仓储管理中信息滞后、库存精度低及流程不可追溯的问题。通过引入 RBAC 权限模型、乐观锁并发控制及基于规则的库位推荐算法，系统实现了从入库、库内管理到出库的全流程数字化闭环。实验表明，该系统在 500 并发下响应时间低于 200ms，库存准确率提升至 99.9%。

## 1. 研究背景与问题定义 (Background & Problem Definition)

### 1.1 研究意义
在供应链数字化转型的浪潮下，仓储管理系统 (WMS) 已成为企业降本增效的核心引擎。传统的 WMS 系统往往存在部署复杂、用户体验差、数据孤岛等问题。本课题旨在设计并实现一套轻量级、高可用、易扩展的现代化 WMS，为中小企业提供低成本的仓储数字化解决方案。

### 1.2 核心问题
当前仓储管理主要面临以下挑战：
- **数据孤岛**：基础资料、入库、出库环节数据不互通，导致信息流断裂。
- **并发冲突**：多用户同时操作同一 SKU 时，易出现“超卖”或库存扣减异常。
- **可审计性差**：缺乏对关键业务动作（如强制盘盈盘亏）的细粒度追踪。
- **操作效率低**：缺乏智能化的路径规划和库位推荐，依赖人工经验。

### 1.3 本文创新点
1.  **基于状态机的业务流转控制**：设计了可配置的订单状态机，确保业务流程的合规性与可追溯性。
2.  **乐观锁库存并发控制机制**：在无锁性能与数据一致性之间取得平衡，有效解决高并发下的库存超卖问题。
3.  **前后端分离的现代化架构**：采用 Vue3 + Django 的松耦合架构，提升了系统的可维护性与前端交互体验。

## 2. 系统总体架构 (System Architecture)

系统采用典型的 **C4 模型架构**，分为表现层、通信层、业务逻辑层和持久化层。

### 2.2 技术栈选型 (Technology Stack)

| 层次 | 技术组件 | 选型理由 |
| :--- | :--- | :--- |
| **前端** | Vue 3 + Vite + Pinia | 组件化开发、极速构建、响应式状态管理，提升用户体验。 |
| **UI 框架** | Element Plus | 丰富的企业级组件库，保障界面统一性与开发效率。 |
| **后端** | Python 3.10 + Django 4.2 | 成熟的生态、内置的高安全性（CSRF/XSS 防御）及强大的 Admin 管理。 |
| **API** | Django REST Framework | 自动化的序列化、标准化的 OpenAPI 文档生成。 |
| **数据库** | MySQL 8.0 | 支持 ACID 事务，保障库存扣减等核心业务的数据强一致性。 |
| **认证** | SimpleJWT | 无状态认证机制，便于水平扩展和跨域访问。 |
